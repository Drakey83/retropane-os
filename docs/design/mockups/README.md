# Weather mock-ups: the Sunburst icon pack

Design mock-ups of the Today screen with the weather icons of the "Sunburst"
pack. They are pictures, made from an HTML layout and rendered at 2x (the
screen is 480 x 640). All sample data (temperatures in degrees Fahrenheit, wind in mph,
the city, the calendar) is made up.

| Image | What it shows |
|---|---|
| `today-lake-clear.jpg` | Clear sky, mountain-lake wallpaper |
| `today-lake-heavy-rain.jpg` | Heavy rain, the same wallpaper |
| `today-night-clear.jpg` | Clear night, a plain night gradient |
| `today-dusk-thunderstorm.jpg` | Thunderstorm, a plain dusk gradient |
| `themes-montage.jpg` | Six screens, each with its own wallpaper and icon pack (Sunburst, Golden Hour, Aurora, Frosted, Chrome, Noir), to show the look is customisable |
| `sunburst-icons.jpg` | All 22 icons, each at full size, at 96 px and at 48 px |

The look is the smoked-glass design in [../ui.md](../ui.md); the weather
plan is in [../weather.md](../weather.md).
