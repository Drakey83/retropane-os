# Design mock-ups: the Today screen

Design mock-ups of the Today screen with the default weather icons (VClouds').
They are pictures, made from an HTML layout and rendered at 2x (the screen is
480 x 640). All sample data (temperatures in degrees Fahrenheit, wind in mph,
the city, the calendar) is made up. They are not screenshots: the shell is
still in design.

| Image | What it shows |
|---|---|
| `themes-montage.jpg` | Six screens over six wallpapers (the picture on the front page) |
| `today-clear.jpg` | Clear sky |
| `today-heavy-rain.jpg` | Heavy rain, a black-and-white wallpaper |
| `today-night-clear.jpg` | Clear night |
| `today-thunderstorm.jpg` | Thunderstorm |
| `vclouds-icons.jpg` | The 22 icons the Today screen uses, each at its own size, at 96 px and at 48 px |
| `optional-packs.jpg` | The five optional icon packs (not on the front page): six of the 22 icons each |

The look is the smoked-glass design in [../ui.md](../ui.md); the weather
plan is in [../weather.md](../weather.md).
