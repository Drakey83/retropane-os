# First probe run on a real X51v (2026-10-11)

The owner's Dell Axim X51v (WM 6.1 Classic ROM, CE 5.2.20273), booted into
`rp-probe` (build `8bd30913+`) by HaRET from the SD card. Read from four phone
photos; **every one of the 108 report lines matched its checksum**, so no
digit below is a misreading. Confidence for every value: **confirmed**
(measured once, on one device, in the state Windows Mobile and HaRET left it).

## What it tells us

| Fact | Value | Meaning |
|---|---|---|
| Core clock | run 208 MHz, turbo **520 MHz**, turbo on, fast bus (`CCSR 0x30000290`, `CLKCFG 0xB`) | WM was not running at the chip's 624 MHz maximum |
| SDRAM | `MDCNFG 0x0ACB2BCC`, `MDREFR 0x201EE030`, `MDMRS 0x00320032` | Dell's SDRAM setup, needed to own the memory controller later |
| Static memory | `MSC0 0x128238D8`, `MSC1 0x24842481`, `MSC2 0x7FF47FFC` | chip-select timings (flash, 2700G on CS3, CPLD) |
| Backlight PWM | `PWMCR0 1`, `PWMDCR0 0x33`, `PWMPCR0 0xD7`; PWM1 `1`/`0x46`/`0xD7` | duty 51/215 and 70/215 as WM left them (backlight on one of them; to confirm) |
| PXA LCD controller | `LCCR0 0` (off) | the panel is driven by the 2700G, not the PXA's own LCD controller |
| Wake sources | `PWER 0x80007803` | GPIO0, GPIO1, GPIO11-14 and RTC alarm wake the device (power work) |
| SD card | SDHC, RCA `0x0001`; partition 1 type `0x0C` (FAT32 LBA), start 8192, 7,798,784 sectors | our SD driver works on hardware |
| Panel | 3.7" Sharp VGA | CPLD panel ID decode confirmed |
| 2700G plane | see `2700g.md`; display timings `DHT*`/`DVT*` below | answers an open question in `2700g.md` (the encoded timing values) |
