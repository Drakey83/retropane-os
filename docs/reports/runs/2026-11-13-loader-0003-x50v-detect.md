# loader-0003 (X50v), 2026-11-13: the loader finds the X50v by itself, R193

- **Unit:** the owner's X50v (Windows Mobile 2003, in its cradle with
  ActiveSync connected), HaRET and the loader (`c66a0693`) started from its
  own CF card's plain `RetroPane` folder (empty command line); an SD card
  in.
- **Card log:** `loader-0003` on its SD and CF cards, read over its own USB
  with `cargo xtask cardlog loader`; kept in `local/cardlog/loader-0003.txt`.
- **Verdict: both fixes proven.**
  - **Detection:** CPLD `0x06` `000B` named the X50v, and the loader
    switched bit 3 on by itself (`docs/research/sheets/r193-x50v-detect.md`).
  - **The stale configuration error:** Windows Mobile handed over UDCCR
    `0x808` (EMCE set) again. The previous loader read that as its own
    failure ("USB unavailable", loader-0002, `local/x50v-rplog/log-01.txt`).
    This loader cleared it, and the PC configured the serial + drive layout
    at 1.4 s.
